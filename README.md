([Read more](/details/basin.md)) `Freemium` `API` `Form Backend`
- [Form.io](https://www.form.io/) - Form.io is an open-source form and data management platform with an API-first approach. ([Read more](/details/formspree.md)) `Freemium` `API` `Form Backend`

- [LimeSurvey](https://www.limesurvey.org/) - LimeSurvey is a self-hosted, open-source survey tool for creating complex questionnaires and polls. It is for researchers and organizations needing full data ownership and advanced survey logic. The community edition is free and open source. ([Read more](/details/limesurvey.md)) `Open Source` `Self-Hosted` `Enterprise` `API`
- [SurveyJS](https://surveyjs.io/) - SurveyJS is a set of open-source JavaScript libraries for embedding dynamic surveys and forms into web applications. It is for developers who need to build custom form interfaces with full control over rendering and data. Core libraries are open source; commercial tools are also available.
